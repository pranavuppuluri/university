# Object detection

Detection and classification notebooks from August and November 2024.

| Notebook | What it is |
| --- | --- |
| `yolov8-training.ipynb` | Training a YOLOv8 model with Ultralytics on a custom dataset, run on Colab |
| `drones-cbam.ipynb` | Drone image classification with a CNN that adds CBAM attention blocks, in PyTorch |

Datasets are not included. Both notebooks expect data on Google Drive or the
Kaggle input path.
