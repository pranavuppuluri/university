# Speech and language processing

Lab work and the course project from the speech and language processing course,
October and November 2024.

| Notebook | What it is |
| --- | --- |
| `text-classification-comparison.ipynb` | CountVectorizer, TF-IDF, Naive Bayes and SVM compared on one text dataset |
| `lab-6a.ipynb` | Lab exercise 6a |
| `watson-speech-to-text.ipynb` | Transcription with the IBM Watson speech to text API. Credentials are placeholders |
| `bert-fine-tuning.ipynb` | Fine tuning BERT for classification |
| `sentiment-analysis.ipynb` | Custom sentiment classifier on SMS text |
